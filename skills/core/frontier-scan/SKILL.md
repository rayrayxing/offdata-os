# Frontier Scan

Search primary technical sources, release notes, open source, papers and current discourse for changes from roughly the last 6–24 months. Ask: **what is materially possible/cheap/reliable now that was not before?**

For each signal record capability, change magnitude, maturity, cost/quality change, constraints, source/provenance, occurrence/retrieval dates and plausible affected contexts. Do not propose viability as fact; hand off Signals to Technology Transfer/Context Translator.
