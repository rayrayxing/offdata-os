# Evidence Collection

Capture original source/interaction, occurrence time, retrieval time, provider/channel, identities where legitimately known, receipt and content hash. Set intended purpose; call deterministic `evidence_validate`. Never infer a missing direct-buyer tuple field. Research may inform strategy but cannot become authoritative G3 merely because it is persuasive.
