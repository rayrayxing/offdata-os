# Skill Audit

Inspect instructions and referenced scripts/resources. Test normal/adversarial cases, untrusted input boundaries, secrets/tool escalation, output contract and known failure modes. Recommend TESTED/CERTIFIED only with evidence. No Skill may silently rewrite evidence, gates, finance, authority or security policy.
