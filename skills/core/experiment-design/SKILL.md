# Experiment Design

Optimize information gained / dollars / time. Define principal uncertainty, falsifiable hypothesis, target, intervention/prototype, success/failure, stopping rule, budget/time, evidence/attribution and analysis method. Prefer interviews/observation/fake door/outbound/concierge/Wizard-of-Oz/LOI/preorder before expensive product when sufficient. Prototype Authorization is separate from G3.
