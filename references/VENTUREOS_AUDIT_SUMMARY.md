# Prior VentureOS Independent Audit Lessons

This is a regression-design summary, not a substitute for the original audit files/current source.

Carry these defects permanently into off/data adversarial certification:

## Authority / evidence
- incomplete direct buyer attribution could still contribute to G3;
- legacy URL/domain/weaker-field fallbacks could become authoritative;
- invalid evidence taxonomy lacked adequate DB enforcement;
- approval paths could fabricate downstream authority;
- stale predecessor/gate remained valid after material evidence mutation/quarantine.

## Environment / finance
- TEST/SIM paths could create authoritative-looking LIVE financial/customer state;
- closed financial periods/snapshots were mutable/backdatable;
- authoritative G9/G10/cockpit decisions lacked one immutable snapshot identity;
- scale decisions/approvals could bypass required predecessor semantics.

## Reliability / audit
- duplicate progression created duplicate logical artifacts;
- G10 request creation lacked concurrency idempotency;
- audit lineage/provider receipts were incomplete;
- zero-history telemetry could fabricate 100% readiness instead of insufficient history;
- migrations/typechecks/real model path were not always reproducible.

## Research / product / security
- synthetic last30days provider behavior existed instead of real integration;
- SmartResearchRouter path claims did not match worker runtime;
- external research prompt injection could enter model prompts;
- generated prototype HTML created same-origin XSS exposure;
- prototypes could be decorative rather than test critical uncertainty;
- generated concepts/communications could invent commercial certainty;
- UI counters could count inadmissible buyer/WTP-like signals as authoritative.

## off/data consequence
All of these become explicit tests in `certification/CODEX_CERTIFICATION.md`; builder self-attestation never closes them.
