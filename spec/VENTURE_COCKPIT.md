# Venture Cockpit

Build as a Hermes dashboard plugin reading canonical Venture Brain.

## Portfolio view

- available/deployed/reserved capital;
- signals/theses/research/prototypes/validation/operating/killed counts;
- venture tournament and marginal capital recommendations;
- active experiments and budgets;
- Skill/capability gaps;
- exceptions/circuit breakers;
- latest AARs;
- portfolio forecasts/calibration/economic outcomes.

## Venture view

- thesis / why now;
- current BusinessConcept revision;
- phase / current authoritative gate;
- next autonomous action;
- research + claim grounding;
- concern register by severity;
- experiment/prototype/validation;
- G0–G10 snapshots;
- customer/contact/interactions;
- revenue/economics/capital;
- decisions/forecasts;
- audit/receipts;
- learning/AAR.

## Truth semantics

Never label raw independent-buyer/WTP-like research as authoritative. Show separately:
- research signals;
- potential buyer signals;
- G3-admissible buyers;
- WTP-like signals;
- G3-admissible WTP.

Distinguish `NOT_YET_PROVEN`, `BLOCKED`, `FAILED`, `IN_PROGRESS`.
