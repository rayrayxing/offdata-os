# Profile Setup

Create one Hermes profile per entry in `PROFILE_MATRIX.yaml` plus dynamic `venture-gm-<slug>` for each serious venture.

Profile SOUL/instructions should contain role mandate, optimization metric, explicit anti-goals and expected handoff schemas. Keep factual venture state out of profile memory.

Start all profiles in `SHADOW`; provision only minimum tools/credentials needed. A profile permission declaration is not enforcement: authoritative action is checked again by Venture Brain policy/hooks.

Dynamic Venture GM may coordinate specialists and propose capital/strategy but cannot admit evidence, pass gates, bypass audit or self-authorize spend.
